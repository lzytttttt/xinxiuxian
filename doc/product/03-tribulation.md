# 03 · 天劫 · 飞升 · 仙界篇

终局与二周目内容。**这是全局仪式感最强的部分**，视觉与文案都要给足。

## 一、九重天劫（凡界终局）

### 触发条件

```
未突破本年 且 等级 ≥ 91（渡劫境） 且 (模拟点 − 年龄) ≤ 0
```

即"模拟点将尽的最后一年"。**渡劫不是随时可做的选择，而是生命走到尽头时的最后一搏**——这是参考实现最有力的设计之一，必须保留。

> 边界：若该年突破成功，则不触发天劫（多活一年）；若模拟点耗尽当年恰好突破，天劫顺延。这个"多活一年"的缝隙是玩家的最后一点操作空间。

### 九重战力阈值

| 重 | 战力要求 |
|---|---|
| 第一重 | 2,500,000 |
| 第二重 | 2,600,000 |
| 第三重 | 2,700,000 |
| 第四重 | 2,850,000 |
| 第五重 | 3,000,000 |
| 第六重 | 3,250,000 |
| 第七重 | 3,500,000 |
| 第八重 | 3,850,000 |
| 第九重 | 4,250,000 |

**同年连渡九重**，逐重判定：

```
req = TRIB_REQ[i] × (1 − fateTrib / 100)

1. 总战力 ≥ req                     → normal（硬实力渡过）
2. rand() < 气运 / 5000             → lucky（侥幸渡过）
3. 有仙灵气 → 消耗 1 缕              → xianqi（祭出仙灵气，天劫应声而散）
4. 否则                             → 身死道消
```

**侥幸概率 = 气运 / 5000**，即气运 100 → 2%，气运 500 → 10%。这是气运在终局的唯一价值兑现点。

### 每重收益

| 重 | 修为倍率 |
|---|---|
| 1 | ×1.01 |
| 2 | ×1.02 |
| 3 | ×1.03 |
| 4 | ×1.04 |
| 5 | ×1.05 |
| 6 | ×1.06 |
| 7 | ×1.07 |
| 8 | ×1.08 |
| 9 | ×1.10 |

**九重全过额外 +10,000,000 修为。**

### 结局分支

| 结果 | `ascendMode` | 后续 |
|---|---|---|
| 九重全渡 | `immortal` | 等级锁定 100，模拟点设为 99999，弹出飞升弹框 |
| 中途失败 | `fail` | 身死道消，记录 `tribPassed`（已渡重数）供成就判定 |

**飞升弹框**提供两个选项：
- **继续·仙界篇** → 进入仙界
- **就此结算** → 按飞升结算（`ASCEND_EXP = 1000` 经验）

## 二、飞升

```
enterImmortalRealm(g)：
  realm = 2
  等级 → 101（仙人一重）
  修为 × IMMORTAL_BOOST = 12
  模拟点 → 999999（占位，仙界不限时）
  仙灵气 +1（飞升默认带一缕）
  混沌气 = 0（不白送，否则仙劫形同虚设）
  天劫重数归零，事件计数重置
  ascended = false（仙界篇继续修行，不再是结束态）
```

**`IMMORTAL_BOOST = 12` 是关键**：飞升瞬间修为 ×12，把凡界末期的百万量级拉到仙界所需的千万量级，同时保持"刚飞升就是仙界最弱"的体感（仙界机缘 11 档起跳就是 300 万战力）。

**混沌气不白送**是刻意设计：如果飞升送混沌气，仙劫就可以无限免战力度过，仙界篇会变成无风险散步。

## 三、仙界节奏与风险

### 仙劫（每跨大境界）

等级 110/120/…/190 触发。

```
参考值 IMM_GATE_REQ[境内阶-1]：
  [269M, 386M, 557M, 794M, 1110M, 1540M, 2160M, 3050M, 6040M]

通过率 = IMM_GATE_PASS[境内阶-1] × (clamp(战力/参考值, 0.3, 3))^0.6
  IMM_GATE_PASS = [0.95, 0.90, 0.86, 0.82, 0.78, 0.74, 0.70, 0.66, 0.62]
  封顶 0.97，下限 0.05
  参考值可被 fateTrib 降低

失败 → 仙躯寸寸崩解，道消身陨
成功 → 修为 ×1.12，immGates++
```

**战力越高越易过，但基础概率逐境递减**——保证难度单调递增，避免"后期无敌"。

### 走火入魔（软性时限）

```
风险 = min(0.06, 0.004 + 仙界滞留年数 × 0.00008)
  IMM_PERIL_BASE = 0.004, IMM_PERIL_SLOPE = 0.00008, IMM_PERIL_MAX = 0.06

命中时：
  有混沌气 → 消耗 1 缕，修为 −= 修为 × rand(3%, 8%)，perilSurvived = true
  无混沌气 → 道消身陨
```

**这是仙界篇的节拍器。** 滞留越久风险越高（第 1 年 0.4%，第 250 年触顶 6%），逼玩家推进而不是无限磨。凡界靠模拟点倒计时，仙界靠走火入魔——两套机制同一个目的。

### 混沌气

```
仙界每年 1/100 获得一缕（受气运与命格「仙灵气概率」加成）
每缕伴随修为 +rand(2000万, 4000万)
用途：免战力度过仙劫 / 证道天劫一重，或化解走火入魔
```

## 四、证道天劫

等级达到 200（道祖圆满）触发。

| 重 | 战力要求 |
|---|---|
| 1-9 | [612亿, 646亿, 680亿, 714亿, 748亿, 782亿, 816亿, 850亿, 884亿] |

倍率 `TRIB_MULT2 = [1.03, 1.05, 1.07, 1.09, 1.12, 1.15, 1.18, 1.22, 1.30]`，九重全过额外 **+50 亿**修为。

判定逻辑与凡界天劫一致，但消耗的是**混沌气**而非仙灵气。

**结局**：`ascendMode = 'zhengdao'`，等级锁定 200，文案"大道加身，你证道成圣，自此超脱仙域，与道合真"。

## 五、结局枚举

```ts
type RunEndReason =
  | 'simDepleted'    // 模拟点耗尽（凡界，未达渡劫境）
  | 'tribFail'       // 九重天劫失败
  | 'immortal'       // 飞升（选择就此结算）
  | 'gateFail'       // 仙劫失败
  | 'peril'          // 走火入魔
  | 'zhengdao'       // 证道成圣
  | 'voluntary'      // 玩家主动提前结算
```

| 结局 | 结算经验 |
|---|---|
| 飞升 | `ASCEND_EXP = 1000` |
| 普通结算 | `等级 × 0.5` |
| 提前结算 | `等级 × 0.1` |

**玩家等级经验**：升到第 n 级需 `50 × n` 经验（累计 `25 × n × (n+1)`）。

## 六、视觉与文案要求

| 事件 | 视觉 | 文案基调 |
|---|---|---|
| 天劫降临 | `劫雷`：三道白闪（80ms 各）+ 屏幕亮度冲击 | 短句、急促、以「！」收尾 |
| 渡劫成功 | 彩虹流光文字 | 释放感，修为数字要大 |
| 渡劫失败 | `碎裂`：抖动 + 红色粒子 | 戛然而止，不拖沓 |
| 飞升 | `飞升`：全屏金白光柱 2200ms | 长句、庄严、留白 |
| 证道 | `飞升` + `顿悟` 叠加 | 极简，一句收尾 |

**所有天劫相关日志统一用彩虹色（`cls: 'rainbow'`）且以「！」收尾**——这是参考实现的约定，保留。视觉强度受"低/中/高"设置门控（见 [tech/04-visual.md](../tech/04-visual.md#六动画词表)）。

## 七、移植红线（本篇相关）

| # | 红线 | 为什么 |
|---|---|---|
| 8 | **九重天劫同年连渡** | 终局的集中爆发，仪式感来源。改成逐年渡劫会彻底毁掉高潮 |
| — | **触发条件是"模拟点将尽"而非玩家选择** | 生命倒计时驱动的终局，比"点按钮渡劫"有力量得多 |
| — | **飞升不白送混沌气** | 否则仙界篇无风险 |
| — | **仙界用走火入魔而非模拟点做节拍器** | 仙界不限时，需要另一套压力来源 |
