# 00 · 产品总览

## 一、产品定位

**中文网页修仙人生模拟器**。单局 = 一世修行：抽灵根入道 → 逐年静修突破 → 历机缘、降法宝、炼丹药、入宗门、结羁绊 → 模拟点耗尽时引动九重天劫 → 飞升仙界 → 证道成圣或身死道消。

跨局 = 传承：每一世为下一世积累传承点，解锁洞府、功法、丹方、开局选项。

**目标体验**：25-45 分钟一局，一局之内有 25-60 个真实决策，一局之后有明确的"下一世要换条路走"的冲动。

---

## 二、与参考实现的关系

| 维度 | 参考实现 | 本作 |
|---|---|---|
| 代码 | 6 个 UMD 文件 / 8156 行 / 零依赖 | React + Vite + 纯 TS 引擎，编译器强制分层 |
| 文案 | 原站原创，135 事件 + 2000 名称 | **全部原创重写**，不搬运任何文本 |
| 玩家决策 | **全局仅 1 处**（机缘弹框的争夺/放弃） | 约 480 个决策点（200 事件 × 平均 2.4 选项）+ 炼丹小游戏 |
| 构筑 | 仅开局抽 2 张命格，局内无变化 | 六乘区 × 六流派，局内持续成长与取舍 |
| 长期养成 | 图鉴 + 成就 + 保底，无跨局能力积累 | 传承点 + 洞府六室 + 历史职位 + 前世道侣 |
| 内容量 | 135 事件 / 约 84KB 文案 | 200 事件 / 约 180KB 文案 / 约 8.5 万条生成名称 |
| 事件格式 | JS 闭包，无法批量调平衡 | 声明式效果 DSL，可校验、可模拟、可调参 |
| 随机性 | 裸 `Math.random()`，不可复现 | 具名 RNG 流，种子可复现、可重放、可回归测试 |

**我们保留的**：核心循环的节奏感、机缘的赌博质感、突破的查表概率曲线、飞升的仪式感。详见 [01-core-loop.md 移植红线](01-core-loop.md#七移植红线)。

**我们修掉的**：决策真空、法宝零风险单向棘轮、事件即代码、`maxCount` 是唯一防重复机制、仙界事件漏标 `realm` 就静默失效。

## 三、四大痛点与解法

用户对参考实现的原话判断是「很好玩但是我没有玩爽」。根因拆解与对应设计：

| 痛点 | 根因 | 解法 | 详见 |
|---|---|---|---|
| **决策太少，全程挂机看结果** | 135 个事件全部由内部谓词自动判定，抽中即结算，玩家只是观众 | 事件改为 2-4 选项的显式分支（含资源门槛与风险提示）；新增控火炼丹小游戏；渡劫前的资源投入决策 | [02](02-encounter-fate.md) [05](05-alchemy.md) |
| **没有构筑和 combo** | 只有开局抽的 2 张命格，局内 build 无变化；灵根仅是 ×1.2 的隐形倍率 | 六乘区体系 + 六流派共鸣 + 战力构成面板，让每个乘区可读、可比、可换 | [04](04-arts-build.md) |
| **单局太短，没有长期养成** | 结算只给图鉴/成就/保底，跨局无能力积累 | 传承点 + 洞府六室 + 历史职位 + 前世道侣；保底只保留灵根维度以专注防挫败 | [08](08-legacy-cave.md) |
| **内容量不够，很快就见底** | 手写 2000 条名称仍有跨档重复；事件无冷却无记忆 | 200 事件 × 平均 2.4 选项 + 冷却 8-15 年 + 组合式名称生成（约 600 token → 约 8.5 万条） | [09](09-content.md) |

## 四、核心循环总图

```
┌─ 跨局层（持久）──────────────────────────────────────────────┐

└───────────────────────┬──────────────────────────────────────┘
                        │ 传承点兑换开局优势
                        ▼

│                                                              │
│  ① 入道   抽灵根 / 气运 / 命格（3 选 1，可自定义）            │
│              │                                               │

│              │                                    │           │
│              │   突破/静修 → 丹毒衰减 → 悟性结算   │           │

│              │   → 法宝(5%) → 机缘(5%) → 灵气      │           │
│              │   → 羁绊 tick → 走火入魔 → 天劫判定  │           │
│              │   → 弹框仲裁（每年最多一个）          │           │
│              │                                    │           │
│              │◄───────────────────────────────────┘           │
│              │                                               │

│              │                                               │
│  ④ 结算   模拟点耗尽 → 九重天劫                               │
```

## 五、一局的时间轴（典型 90 年局）

| 阶段 | 年份 | 主要事件 | 决策密度 |
|---|---|---|---|
| 入道 | 第 1 年 | 三选一抽卡、选功法流派 | 2-3 |
| 筑基期 | 1-30 年 | 首个羁绊、加入宗门、第一次炼丹、早期机缘 | 低（约 8-12） |
| 金丹-化神 | 30-60 年 | build 成型、宗门晋升、法宝积累、丹毒管理 | 中（约 10-18） |
| 出窍-大乘 | 60-85 年 | 流派共鸣定型、渡劫准备、高光时刻 | 高（约 8-15） |
| 渡劫 | 85-90 年 | 九重天劫同年连渡 | 集中（3-6） |
| 仙界篇 | 101-200 年 | 仙劫、走火入魔、混沌气、证道 | 视是否续玩 |

## 六、术语表

> **术语必须统一。** 新增术语先加此表再使用。

### 资源

| 术语 | 英文/代码 | 含义 |
|---|---|---|
| 修为 | `cultivation` | 主战力数值，靠突破与事件增长 |
| 灵根 | `root` | 1-100+，十档（杂灵根→道体，>100 称仙体），提供乘区 |
| 气运 | `luck` | 与灵根同档同基数，影响四个概率通道与天劫侥幸 |
| 模拟点 | `simPoints` | 生命预算，逐年递减，归零即终局 |
| 法宝之力 | `artifactPower` | 降服法宝累积的第二战力源 |
| 法宝加成 | `artifactBonus` | 法宝项的独立乘区，基准 100（×1.0） |
| 仙灵气 | `xianqi` | 凡界稀有消耗品，可免战力度过一重天劫 |
| 混沌气 | `chaosQi` | 仙界对应物，可免战力度过仙劫/证道天劫或化解心魔 |
| 悟性 | `insight` | 功法升级货币 |
| 丹毒 | `toxicity` | 0-100，服丹累积，有衰减与两个惩罚 |

### 境界

| 术语 | 含义 |
|---|---|
| 凡界 | 等级 1-100，十阶：练气/筑基/金丹/结婴/化神/出窍/反虚/合体/大乘/渡劫 |
| 重 | 每阶 10 级，个位数即"重"（如 23 级 = 金丹三重） |
| 仙界篇 | 等级 101-200，十境：仙人/真仙/天仙/玄仙/金仙/太乙/大罗/准圣/混元/道祖 |
| 大境界顶 | 等级为 10 的倍数时（10/20/…/90），触发境界抬升 |
| 关口 | 等级个位为 9 时（9/19/…/89），突破概率暂时减半 |
| 连破 | 基础概率 >25% 时同一年连续突破多级 |

### 系统

| 术语 | 含义 |
|---|---|
| 机缘 | 遭遇战对象，有隐藏战力与模糊显示区间 |
| 档位 | 1-20 的品级刻度，机缘/法宝/功法/药材共用 |
| 命格 | 开局抽取的 2 张增益卡，6 属性 × 4 颜色矩阵 |
| 保底 | 跨局累积的抽卡保险，满 100 必出道体档灵根 |
| 乘区 | 战力的独立乘法因子，共六个（Z1-Z6） |
| 流派 | 剑修/丹修/体修/毒修/雷修/魔修，功法所属 |
| 共鸣 | 已装备功法的流派组合模式，给 Z4 额外加成 |
| 传承点 | 跨局货币，用于升级洞府 |
| 洞府 | 跨局持久基地，六室可升级 |

### 手感相关

| 术语 | 含义 |
|---|---|
| **赌博质感** | 机缘的隐藏战力 vs 模糊区间 + 战斗/逃跑判定不对称，是本作张力的核心来源 |
| **移植红线** | 从参考实现必须原样保留的机制与数值，见 [01-core-loop.md](01-core-loop.md#七移植红线) |
| **软封顶** | 六乘区乘积超过 25× 后的对数压缩，防退化堆叠 |

## 七、成功标准

| 维度 | 标准 | 验证方式 |
|---|---|---|
| 单局节奏 | 25-45 分钟 / 60-140 年 / 25-60 决策 | `tsx tools/sim.ts --pacing` |
| 构筑有效性 | L30/50/70/90 上 `P_build / P_nobuild ∈ [2.0, 4.5]` | `tsx tools/balance.ts` |
| 炼丹技能性 | 最优策略均值品质 ≥4.5，随机乱按 ≤1.5 | `npm test -- alchemy` |
| 传承不碾压 | 第 20 世最终等级 ≤ 第 1 世的 1.35× | `tsx tools/sim.ts --lives 20` |
| 移植保真 | 50 种子黄金回归，槽 1-9 数值精确一致 | `tsx tools/sim.ts --golden` |
| 确定性 | 同种子 + 同选择序列 → 逐字节相同日志 | `npm test -- replay` |
| 内容合法性 | 校验器 0 error、0 孤儿 flag | `tsx tools/validate-content.ts` |
