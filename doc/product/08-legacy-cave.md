# 08 · 传承与洞府

**解决"单局太短，没有长期养成"痛点的跨局层。**

设计原则：**传承点买的是"起跑线更高、可选 build 更多"，而不是"上限更高"。** 这一条决定了整个系统的数值方向。

---

## 一、传承点

### 结算公式

```
传承点 = 境界分 + 飞升分 + 图鉴分 + 宗门分 + 成就分 + 羁绊分

境界分 = floor(历史最高等级 / 5)                          // 100 级 → 20
飞升分 = 飞升次数 × 50                                    // 证道 ×2
图鉴分 = floor(图鉴收集总数 / 20)                          // 2000 条 → 100
宗门分 = Σ(各宗门历史最高职位 × 15)                        // 八宗全宗主 → 240
成就分 = 成就数 × 2
羁绊分 = 道侣羁绊等级 × 10 + 历史羁绊总数 × 2

叛宗系数：defections > 0 时 ×1.15（叛宗者拿得更多，但历史职位记录保留最高值）
```

**典型收益**（实现后按公式实测回填，见 [v0.1.0-07 §七](../../test/xiuxian/doc/v0.1.0-07-legacy-cave.md)）：

| 局况 | 传承点 |
|---|---|
| 新手局（60 级，无飞升，图鉴 60、成就 10） | 35 |
| 普通局（90 级，1 次飞升，图鉴 400、成就 20） | 128 |
| 高手局（100 级，飞升 + 证道，图鉴 1000、成就 40、长老 3、道侣 5） | 351 |
| 完美局（110 级，飞升 + 证道，图鉴 2000、成就 80、八宗长老 3、道侣 5、羁绊 10） | 812 |
| 完美局（八宗**宗主**而非长老） | 932 |

> 原表写的是「30-50 / 90-130 / 250-350 / 600-700」。前三档实测落在区间内，**最后一档不成立**：
> 按本文档自己的公式，八宗长老已是 `8 × 3 × 15 = 360` 分（宗主 480），加上其余五项下限就是 812。
> 表格以公式为准，已按实测回填。

**传承点收入随境界线性增长，而洞府升级成本按 `1.6^n` 递增**——收益递减天然存在。

## 二、洞府六室

每室 0-5 级，用传承点升级。

| 房间 | 效果 | 升级成本（1→5 级） | 满级总成本 |
|---|---|---|---|
| **药园** | 每年产 `等级` 株药材（`等级` 0-5，六种基础药材按年份轮转） | 20 / 32 / 51 / 82 / 131 | 316 |
| **丹房** | 炼丹品质 `+等级 × 0.15`，与门派/共鸣/宗门加成同一层叠加 | 25 / 40 / 64 / 102 / 164 | 395 |
| **藏经阁** | 功法升级悟性 `−等级 × 5%`（满级 −25%，成本下限 1） | 30 / 48 / 77 / 123 / 197 | 475 |
| **悟道室** | 悟性收入 `+等级 × 0.5`/年；L2 给第 4 功法槽，L4 给第 5 | 35 / 56 / 90 / 143 / 229 | 553 |
| **聚灵阵** | Z1 `+等级 × 4%` | 30 / 48 / 77 / 123 / 197 | 475 |
| **静室** | Z1 `+等级 × 5%`；**额外**模拟点消耗 `−等级 × 0.5%` | 40 / 64 / 102 / 164 / 262 | 632 |

**六室全满需 2846 传承点**——约 6-10 个高手局。这是刻意的长线目标。

> **静室的「模拟点消耗」只作用于额外消耗**（魔修协同的掠夺），不碰基础寿元。`simPoints` 在本作里
> 就是寿元，整体下调等于直接买等级，与 §四 的防碾压前提正面相撞。见 [v0.1.0-07 §三·2](../../test/xiuxian/doc/v0.1.0-07-legacy-cave.md)。
>
> **药园不是平摊的 Z5 供给**：药材多了丹毒也涨，Z5 的「丹毒惩罚」项会把药力吃回去一部分。
> 实测「正常吃丹」群体的 Z5@L90 由 1.33 降到 1.17。药园真正服务的是毒修那条「刻意嗑低品质
> 把丹毒顶满 → 毒体」的打法。

### 升级阶梯

成本公式：`base × 1.6^(level)`，四舍五入到整数。上表已算好。

## 二·五、前世道统（洞府满级后的第二出口）

> Phase 7 补充。设计动机见 [v0.1.0-07 §七·10](../../test/xiuxian/doc/v0.1.0-07-legacy-cave.md)：
> 洞府满级后传承点无处可花，实测第 20 世余额仍有 948。

洞府六室全满（合计 2846 点）之后，Z1 已被 `聚灵阵 + 静室` 顶到硬上限 ×3.0，**再买洞府一文不值**。
道统是第二个花销口：同样用传承点，换的是**起手就持有**的东西。

| 类别 | 条数 | 落点 | 成本 |
|---|---|---|---|
| 功法道统 | 12（六流派 × 玄品/天品各一） | 起手**持有**该功法一级 | 130 / 220 |
| 丹方道统 | 7（七类丹药各取最高阶丹方） | 起手**已知**该丹方 | 70-230 |
| 药圃道统 | 6（第 1/3/5/7/9/10 阶） | 起手持有该阶药材 `8 + 阶 × 3` 株 | 62-260 |

全表总价约 **4200 点**，高于洞府满级的 2846。**故意让玩家买不全**——传承点全部花光意味着
玩家没有别的世可传承，末期积累会失去意义。

### 道统买不到什么

这是道统最重要的约束，和洞府同源（见 §四）：

| 项 | 能否用道统买到 |
|---|---|
| 灵根档位 | **否**（灵根 → `talentMult` → 突破概率） |
| 突破概率 / 天劫阈值 | **否** |
| 基础寿元 | **否** |
| 功法**等级** | **否**（只给持有 L1，升级仍要悟性） |
| 功法**槽位** | **否**（持有不占槽，要玩家自己排） |

「持有 ≠ 装配」是这里最强的一道结构：`zones()` 只统计 `slots` 里的功法。
买了满表道统但不排槽，战力**一个字节都不涨**。实测见 `tests/engine/doctrine.test.ts`。

### 道统与 `unlocks` 的区别

`MetaState.unlocks` 记的是「你**曾经见过**什么」——局末结算一直在写，洞天屏一直在显示，
但它**不参与起手注入**。因为到第 10 世它会攒下几十门功法，整包注入等于跨局白送整套构筑，
直接破 6.1。

只有 `MetaState.doctrines`（玩家**花传承点显式买下**的那几条）才产生起手包。两者必须分开存。

## 三、持久 vs 重置

### 持久（`MetaState`）

| 数据 | 说明 |
|---|---|
| `legacyPoints` | 传承点余额 |
| `lifetimeLegacy` | 历史累计传承点（用于成就） |
| `cave: Record<RoomId, number>` | 洞府六室等级 |
| `unlocks.arts / recipes / sects` | 已解锁的功法/丹方/宗门 |
| `sectLegacy: Record<SectId, number>` | 各宗门历史最高职位 |
| `pastLives: LifeSummary[]` | 历史局记录（用于高光与排行） |
| `pastPartners: PastPartner[]` | 前世道侣 |
| `achievements: string[]` | 已解锁成就 |
| `pity` | 保底积分 |
| `codex` | 图鉴收集位串 |
| `totals` | 累计局数/年数/飞升数/最高等级 |
| `settings` | 视觉强度、速度等偏好 |

### 重置（`RunState`）

| 数据 | 说明 |
|---|---|
| 等级、修为、灵根、气运 | 全部重抽/重来 |
| 法宝之力、法宝加成 | 归零 / 归基准 |
| 丹药、药材、丹毒 | 归零 |
| 宗门身份、贡献、职位、张力 | 归零 |
| 当前羁绊 | 归零（道侣按规则进入 `pastPartners`） |
| 功法与悟性 | 归零（已解锁的功法**可选**，但需重新升级） |
| 仙灵气、混沌气 | 归零 |
| 保底进度 | 保留（跨局累积） |

**已解锁功法的处理**：解锁是持久的，但**功法等级每局重置**。这样"解锁更多 build 选项"是传承的收益，而"把 build 练满"仍是每局要做的事——两者不冲突。

## 四、防碾压设计

**目标断言：第 20 世最终等级 ≤ 第 1 世的 1.35×。**

这个断言必须在**设计上**成立，而不只是被测试发现。三条机制：

### 1. 洞府加成全部落在已封顶的乘区内

`聚灵阵` 和 `静室` 给的都是 **Z1**，而 Z1 有 ×3.0 硬上限。传承点堆再多，Z1 也封顶。

同理，藏经阁的悟性折扣影响的是 Z4（上限 ×2.5），丹房影响 Z5（上限 ×2.0）。

**没有任何洞府加成能突破乘区上限。**

### 2. 核心难度曲线完全不随传承变化

| 项 | 是否受传承影响 |
|---|---|
| `BREAK_CHANCE` 突破概率表 | **否** |
| 天劫九重阈值 | **否** |
| 机缘/法宝档位权重与战力表 | **否** |
| 模拟点初始值 | **否**（只受灵根档影响） |
| 走火入魔风险 | **否** |

**传承点买不到突破概率、买不到天劫豁免、买不到更高的机缘档位。**

### 3. 成本递增 vs 收益线性

```
洞府升级成本：base × 1.6^n        （指数）
传承点收入：  随境界线性增长       （线性）
```

指数成本 vs 线性收入 → 收益递减天然存在，不需要额外设计衰减。

**结果**：传承点让玩家**更快达到上限**（起跑线更高），但**上限本身不变**。这符合"长期养成应该有回报，但不该让新玩家无法追赶"的设计伦理。

### 4. 成就只买气运，不买灵根

成就的 `bonus` 加成走 `drawCard` 的 **`goldBoost`**。`goldBoost` **只加权气运档位抽取，不加权灵根档位抽取**。

理由是硬约束：灵根 → `talentMult` → 突破概率，是难度曲线的一环。让成就去抬高灵根档，等于让传承直接买突破概率——实测跨 20 世会把第 1 世等级推到第 20 世等级比的 **1.49×**，直接破 6.1。改成只买气运后，20 世比值降到 **1.15**。

这是 §四「难度曲线完全不随传承变化」在开局那一环的落实点。

## 五、图鉴 · 成就 · 高光 · 排行榜

### 图鉴

| 图鉴 | 条目数 |
|---|---|
| 机缘 | 1000（20 档 × 50） |
| 法宝 | 1000（20 档 × 50） |
| 境界 | 20 |
| 丹药 | 约 35 |
| 功法 | 约 40 |
| 药材 | 约 60 |

用位串压缩存储（`orBits` 位运算），跨局累积。

### 成就

约 80 个，分九组：灵根与境界 · 个人修为 · 法宝 · 总战力 · 渡劫 · 飞升成仙 · 仙界篇 · 机缘图鉴 · 法宝图鉴 · 功法流派 · 丹药 · 宗门 · 羁绊 · 传承。

每个成就给**气运抽取概率加成**（`bonus` 百分点），累加生效，上限 `ACHIEVEMENT_BONUS_CAP = 12`。
**只作用于气运档位抽取**，不作用于灵根档位（见 §四·4）。

### 高光

最多保留 20 条结算记录，按总战力排序。可导出为 PNG 海报（canvas 绘制，参考实现的做法）：
- 境界大字 + 结局色（证道/飞升金、天劫陨落红、模拟失败灰绿）
- 9 行明细（灵根/气运/等级/战力/天劫/轮数/机缘/法宝/丹药）
- 命格与功法的 pill 块
- 支持下载与复制文本

### 排行榜

**纯本地**（localStorage）。分三榜：总战力榜、飞升榜、证道榜。**不做假数据**——参考实现的排行榜是 `localStorage` 假装的，本作明确标注"本地单机榜"，不伪装成全区排行。

## 六、验收标准

| 项 | 断言 | 命令 |
|---|---|---|
| 传承不碾压 | 20 世进程，第 20 世最终等级 ≤ 第 1 世的 1.35× | `tsx tools/sim.ts --lives 20` |
| 洞府加成封顶 | 任何洞府等级下 Z1 不超过 ×3.0 | `npm test -- meta` |
| 难度不随传承变化 | 突破概率/天劫阈值/机缘档位不读取 `MetaState` | `npm test -- meta` |
| 成本递增 | 升级成本单调指数递增 | `npm test -- meta` |
| 存档迁移 | 每步迁移有 fixture 测试 | `npm test -- migrations` |
