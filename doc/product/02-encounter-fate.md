# 02 · 机缘 · 法宝 · 命格 · 保底

---

## 一、机缘（遭遇战）

### 档位生成

```
权重 = TIER_WEIGHTS 副本，第 N 阶（N≥2）时从第 N 档起每档 +(N−1)
保底 = 当前阶 − 1（1-2 阶无保底）
仙界：结果 +10（档位 11-20）
```

`pickEnemyTier` 先按权重随机抽，低于保底则抬到下限。**注意：档位只按玩家 `level` 缩放，绝不按 `power` 缩放**（移植红线第 5 条防护）。

### 隐藏战力 vs 显示区间

```
真实战力 power = irand(ENEMY_COMBAT[tier].lo, ENEMY_COMBAT[tier].hi)     ← 玩家永远看不到
显示区间 lo = max(1, round(power × rand(0.6, 0.9)))
        hi = round(power × rand(1.1, 1.5))
```

档位战力表：

| 档 | 名称 | lo | hi |
|---|---|---|---|
| 1 | 练气级 | 30 | 100 |
| 2 | 筑基级 | 100 | 300 |
| 3 | 金丹级 | 300 | 1,000 |
| 4 | 结婴级 | 1,000 | 3,000 |
| 5 | 化神级 | 3,000 | 10,000 |
| 6 | 出窍级 | 10,000 | 30,000 |
| 7 | 反虚级 | 30,000 | 100,000 |
| 8 | 合体级 | 100,000 | 300,000 |
| 9 | 大乘级 | 300,000 | 1,000,000 |
| 10 | 渡劫级 | 1,000,000 | 3,000,000 |
| 11-20 | 仙人级…道祖级 | ×10 递进，20 档 1000 亿-3000 亿 | |

### 战斗判定 `battleOutcome`（用隐藏 power）

```
总战力 > power          → 必胜（'win'）
总战力 < power × 0.9    → 必败（'lose'）      WEAK_RATIO = 0.9
区间内                  → rand() < 1/3 胜 / < 2/3 平 / 其余 负
```

**平局无奖励无惩罚**——这是"赌一把"的中间态，让玩家在不确定时仍愿意尝试。

### 结算

| 结果 | 收益/代价 |
|---|---|
| **胜** | `修为 += power × 15%`；点数池 `irand(tier, tier×2)` 随机拆给 模拟点/灵根/气运（1:1:1 等概率）；记入 `conquered[]` |
| **平** | 无 |
| **负** | 凡界：`模拟点 −= round(rand(1, tier+1))`（最低 1）；仙界：`修为 −= 修为 × rand(0.5%, 2%)` |

> 仙界不扣模拟点（模拟点在仙界是占位值），改扣修为——风险性质从"缩短寿命"变成"削弱战力"。

### 逃跑判定 `escapeResolve`（用档差，**不用战力**）

```
自身档 > 对方档  → 100%
自身档 = 对方档  → 90%          ESCAPE_SAME = 0.90
自身档 < 对方档  → 90% − 5% × 档差   ESCAPE_STEP = 0.05，下限 0
```

自身档 = `levelTier(lvl) = clamp(ceil(lvl/10), 1, 20)`（仙界不夹到 10，与仙界机缘档位对齐）。

| 结果 | 收益/代价 |
|---|---|
| **脱身成功** | 无损失 |
| **脱身失败** | 凡界：`模拟点 −= round(0.2 × rand(0, tier) + 1)`；仙界：`修为 −= 修为 × rand(0.3%, 1.2%)` |

> ⚠ 参考实现的注释声称逃跑有 45% 下限，但代码实际下限是 0。**本作以代码行为为准（下限 0）**，并在文档中明确——档差过大时逃跑就是不可能。

### 决策点

参考实现只有"争夺/放弃"两个选项。本作扩展为（详见 [tech/02-effect-dsl.md](../tech/02-effect-dsl.md)）：

| 选项 | 条件 | 效果 |
|---|---|---|
| 争夺 | 总是可选 | 走 `battleResolve` |
| 放弃 | 总是可选 | 走 `escapeResolve` |
| **试探**（新增） | 需消耗资源（如 1 缕仙灵气 / 1 颗丹药） | 收窄显示区间（最多收窄到 50%），再走 `battleResolve` |
| **邀战**（新增） | 需有羁绊 NPC 同行 | 助战加成计入战力后走 `battleResolve`，但失败时 NPC 好感下降 |

**"试探"的收窄上限是 50%**——这是移植红线第 5 条防护之一。收窄再多赌博就不存在了。

### 自动策略

玩家可预设策略，避免每次弹框（见 [plan/03-risks.md R5](../plan/03-risks.md#r5)）：

| 策略 | 行为 |
|---|---|
| 手动 | 每次弹框 |
| 一律争夺 | 全走 `battleResolve` |
| 一律放弃 | 全走 `escapeResolve` |
| 智能 | `总战力 ≥ 区间中值 × 阈值` 时争夺，否则放弃（阈值默认 1.0，可调 0.5-3.0） |
| 随机 | 50/50 |

> **智能策略是 dev flag，默认关闭。** 它按"区间中值"判断，而中值 ≈ 真实战力——这等于变相暴露 `power`。开启时本局禁用成就。

## 二、法宝

### 获取

**独立于战斗的年度掷骰**：`5% × luckMult`，跨大境界当年 `50% × luckMult`。没有任何战斗掉落来源。

### 降服

```
降服率：
  自身档 ≥ 法宝档  → 100%
  否则            → (50 − 5 × (档差 − 1)) %      ARTIFACT_RATE_BASE = 50, STEP = 5
                    档差 1 → 50%，2 → 45%，3 → 40%…档差 ≥ 11 → 0%
```

**档位保底**：`当前阶 − 2`（4 阶起生效，即至少筑基阶法宝）。

### 收益

```
降服成功：法宝之力 += round(法宝战力 × 10%)      ARTIFACT_POWER_MULT = 0.10
失败：一无所获（无任何代价）
```

法宝战力取与机缘**同一张档位表**，但**不显示 lo/hi 区间**——法宝是纯概率赌，机缘是信息赌。

### 已知缺陷与修法

> **参考实现的法宝是"零风险单向棘轮"**：失败无代价、永不丢失、永不降级、无装备模型（`fruits[]` 只是战利品列表）。这导致法宝系统没有取舍，只有累积。

本作保留"降服失败无代价"（这是它的爽点，不破坏），但通过**丹药丹毒**引入真实的累积代价系统（见 [05-alchemy.md](05-alchemy.md)），并把法宝接入 **Z3 法宝共鸣乘区**（见 [04-arts-build.md](04-arts-build.md)），让它成为 build 的一环而非纯数值堆叠。

## 三、命格

### 矩阵

每局开局抽 **2 张**，属性不重复。6 属性 × 4 颜色 = 24 项。

**颜色**（权重与数值区间）：

| 颜色 | 权重 | 区间 | 说明 |
|---|---|---|---|
| 绿 | 40 | 5%-10% | |
| 蓝 | 30 | 10%-30% | |
| 紫 | 20 | 40%-60% | |
| 金 | 10 | 60%-100% | 权重受榜单加成提升（最多 +9%） |

**属性**（`full` = 满值）：

| 属性 | 代码 | full | 效果 |
|---|---|---|---|
| 灵根 | `root` | 10 | 绝对加点 |
| 气运 | `luck` | 10 | 绝对加点 |
| 仙灵气概率 | `xianqi` | 50 | 概率 ×(1 + N/100) |
| 法宝加成 | `artifact` | 30 | 绝对加点（基准 100） |
| 突破概率 | `brk` | 20 | 独立乘区 ×(1 + N/100) |
| 天劫要求 | `trib` | 10 | 要求 ×(1 − N/100) |

**数值生成**：`round(full × rand(color.lo, color.hi))`，最低 1。

### 应用

```
root / luck / artifact  → 直接加点
xianqi                  → g.fateXianqi（概率乘区）
brk                     → g.fateBrk（突破概率乘区）
trib                    → g.fateTrib（天劫要求降幅）
```

**命格是本作唯一的"开局即定"的构筑来源**——局内构筑由功法承担（[04](04-arts-build.md)）。

### 榜单加成

```
rankFateBonus(rank)：
  rank 1        → +3%
  rank ≥ 100    → +0.03%
  中间线性插值
  三榜可累加，最多 +9%
```

## 四、保底

### 积分累积

**只保留灵根档位维度**：

| 结算时灵根档 | 积分 |
|---|---|
| 杂灵根（档 1） | +5 |
| 五灵根（档 2） | +4 |
| 四灵根（档 3） | +3 |
| 三灵根（档 4） | +2 |
| 双灵根及以上（档 ≥5） | +1 |

**满 100 触发**：下一次抽卡必出**道体档灵根卡**（灵根 91-100）且**必带 1 张金色命格**。

### 为什么移除等级加成

参考实现还有等级加成（71 级 +2 / 81 级 +3 / 91 级 +5 / 95 级 +8 / 100 级 +10 / 羽化飞升 +30）。**本作全部移除。**

理由：等级加成奖励的是"玩得久"，而这个需求已经由**传承点**承担（[08-legacy-cave.md](08-legacy-cave.md)）。灵根保底奖励的是"玩得差、死得早"，这才是真正的防挫败需求。**两种货币各司其职，不混用。** 混用会导致"高玩拿保底比新手还快"的反直觉结果。

## 五、图鉴与成就

### 图鉴

- **机缘图鉴**：每档 50 种，20 档共 1000 条
- **法宝图鉴**：每档 50 种，20 档共 1000 条
- **境界图鉴**：20 条（凡界十阶 + 仙界十境，各带一句描述）
- **丹药图鉴**：见 [05](05-alchemy.md)

收集进度用位串压缩存储（参考实现的做法，很省空间）：`orBits` 位运算合并。

### 成就

参考实现 50 个，每个给高阶气运抽取概率加成（`bonus` 百分点）。分组：灵根与境界 7 · 个人修为 5 · 法宝 5 · 总战力 5 · 渡劫 9 · 飞升成仙 6 · 仙界篇 12 · 机缘图鉴 11 · 法宝图鉴 11。

本作扩充为约 80 个，新增：
- 功法类（集齐某流派 6 门、达成各共鸣模式）
- 丹药类（炼出仙品、丹毒满值不死、毒修通关）
- 宗门类（晋升宗主、叛宗、八宗全入）
- 羁绊类（同时 5 种关系、道侣双修满级、宿敌化友）
- 传承类（10 世 / 30 世 / 100 世、满洞府）
