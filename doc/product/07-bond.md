# 07 · 羁绊

**解决"没有长期养成"与"决策太少"的人际维度系统。** 让修仙路上有人，且这些人的存在会改变你的战斗与选择。

---

## 一、NPC 生成

```ts
interface Npc {
  id: string;
  name: string;                    // 组合式生成（120 姓 × 200/180 名）
  gender: '男'|'女';
  rootTier: number;                // 1-10，影响其成长速度
  personality: PersonalityTag;     // 性格标签，影响事件走向
  origin: OriginTag;               // 出身，影响初遇场景
  level: number;                   // 同步成长
  affinity: number;                // 好感 0-100
  bondType: BondType | null;
  bondLevel: number;               // 0-5
  alive: boolean;
  metYear: number;
  flags: Record<string, number>;
}

type PersonalityTag = '刚直'|'狡黠'|'淡泊'|'痴狂'|'仁厚'|'孤傲';
type OriginTag = '世家'|'散修'|'宗门'|'妖族'|'皇族'|'乞儿';
```

**性格影响事件走向**：同一个"赠礼"选项，对「刚直」NPC 加好感，对「狡黠」NPC 反而降好感（他会怀疑你有所图）。这让羁绊不是单纯的数值累积，而需要玩家读人。

**出身影响初遇场景与后续剧情**：妖族 NPC 可能带来血脉事件；皇族 NPC 带来世俗势力线。

## 二、五种关系

| 关系 | 建立条件 | 数值效果 | 特点 |
|---|---|---|---|
| **道侣** | 好感 ≥ 80 + 专属事件 | **双修**：每年修为 `+L × 2%` | 唯一能跨局保留的关系 |
| **师徒** | 境界差 ≥ 20 级 + 事件 | **悟性 `+L`**（L = 羁绊等级） | 悟性主要来源之一 |
| **挚友** | 好感 ≥ 60 + 共渡难关 | **Z6 `+L × 2%`** | 直接提升战力乘区 |
| **宿敌** | 战斗失败 + 事件 | **论剑**：每年可挑战，胜利给大量修为；但每年有被挑战风险 | 高风险高回报 |
| **同门** | 同宗门 + 好感 ≥ 40 | **宗门贡献获取 `+L × 10%`** | 加速宗门晋升 |

**关系等级** 0-5，**好感** 0-100。关系等级通过事件与互动推进，好感是关系等级的门槛。

| 羁绊等级 | 好感门槛 | 效果倍率 |
|---|---|---|
| 1 | 20 | ×1 |
| 2 | 40 | ×2 |
| 3 | 60 | ×3 |
| 4 | 80 | ×4 |
| 5 | 100 | ×5 |

## 三、NPC 同步成长

```
NPC 每年成长：level += 突破判定（用其 rootTier 查同一张 BREAK_CHANCE 表）
             速度约为玩家的 60-90%（视 rootTier 与性格）
```

**NPC 会跟着你变强**——不是静态的数值挂件。高境界时重逢低境界的旧友，会有"物是人非"的叙事效果（部分羁绊事件按境界差分支）。

## 四、助战

同行 NPC 在机缘战斗中提供加成：

```
助战加成 = Σ(各同行 NPC 贡献)
单个 NPC 贡献 = bondLevel × 3% + (道侣额外 +5%)
总助战加成 = min(30%, Σ)
```

**30% 是硬上限**（移植红线第 5 条防护之一）。

> **为什么必须硬上限**：机缘的张力来自"你的战力 vs 隐藏战力"的赌局。如果助战能堆到 50%+，玩家就能靠人脉碾平战力曲线，赌局消失。30% 足够让羁绊"有感"，但不至于让战斗失去悬念。

**助战在 tick 槽 11 重算**，用当日战力——所以 NPC 的成长会即时反映。

### 助战的代价

| 情况 | 后果 |
|---|---|
| 战斗胜利 | NPC 好感 +2 |
| 战斗失败 | NPC 好感 −5，且 NPC 可能受伤（进入 3 年不可用状态） |
| 邀战后逃跑 | NPC 好感 −10 |

**带人打架有成本**——这让"要不要带 NPC"成为一个真实的决策，而不是无脑带上。

## 五、羁绊事件

**约 35 个羁绊事件**，作为独立事件池参与 10% 随机事件抽取。

| 类别 | 数量 | 示例 |
|---|---|---|
| **初遇** | 8 | 按出身分场景：坊市冲突、秘境同困、宗门同门、妖兽袭村 |
| **双修/论道** | 6 | 道侣专属双修、师徒传功、挚友论道 |
| **赠礼** | 5 | 送丹药/药材/法宝，按性格判定反应 |
| **共渡难关** | 7 | 同行渡劫、秘境救援、仇家追杀 |
| **背叛** | 4 | 宿敌挑拨、利益冲突、宗门对立、道侣离心 |
| **生死离别** | 5 | 寿元耗尽、渡劫失败、为你挡劫 |

### 关键设计

- **背叛事件有前置条件**（好感骤降、宗门对立、长期未互动），不是随机背刺。
- **生死离别不可逆**——NPC 死亡后 `alive = false`，其提供的所有加成消失。这是"长期养成"的重量来源。
- **每个 outcome 有 3-4 个文本变体**，按 NPC 性格/出身/境界分支。

## 六、局末处理

| 关系 | 局末行为 |
|---|---|
| 道侣（羁绊 ≥ 4） | **进入 `MetaState.pastPartners`**，可在后续某一世通过专属事件重逢 |
| 道侣（羁绊 < 4） | 随这一世终结 |
| 师徒 / 挚友 / 同门 / 宿敌 | 随这一世终结（成就与高光记录保留） |
| 已死亡 NPC | 永久记录在 `MetaState` 的高光档案 |

### 前世道侣

```
条件：上一世道侣羁绊 ≥ 4，且当前世年龄 ≤ 30，且未结道侣
事件：ev_bond_past_lover（权重高，专属池）
效果：重逢 → 直接建立道侣关系，羁绊等级 = max(1, 前世等级 − 1)
      并附带一段专属叙事（"你记得我不记得的事"）
```

**这是长期养成的情感锚点。** 每一世结束时的道侣，会在下一世以"似曾相识"的方式重现——这给了玩家一个跨局的、非数值的延续理由。

## 七、羁绊与其他系统的交互

| 系统 | 交互 |
|---|---|
| 宗门 | 同门羁绊加速贡献；宗门对立 NPC 可能变成宿敌 |
| 丹药 | 赠礼用丹药；道侣双修可用丹药加成 |
| 功法 | 师徒羁绊可传授功法；宿敌论剑可习得对方功法 |
| 机缘 | 邀战选项（见 [02](02-encounter-fate.md)） |
| 传承 | 道侣跨局保留；历史羁绊记录给传承点加成 |

## 八、验收标准

| 项 | 断言 | 命令 |
|---|---|---|
| 助战上限 | 助战加成永不超过 30% | `npm test -- bond` |
| 羁绊可达 | 一局 90 年可建立 3-5 段羁绊 | `tsx tools/sim.ts --bond` |
| 背叛条件性 | 背叛事件仅在满足前置条件时触发，非随机背刺 | `npm test -- bond` |
| 前世道侣 | 满足条件时在 500 局内至少触发一次重逢 | `npm test -- bond` |
| 带人有代价 | 邀战失败时 NPC 好感下降且进入不可用状态 | `npm test -- bond` |
