# 06 · 宗门

**解决"决策太少"与"没有构筑"的中期系统。** 宗门给玩家一条清晰的成长主线，并提供流派专属资源。

---

## 一、八宗门

| 宗门 | 流派倾向 | 身份定位 | 专属资源 |
|---|---|---|---|
| **太虚剑宗** | 剑修 | 剑意凌厉，唯攻不守 | 剑修功法、剑类法宝加成 |
| **青囊谷** | 丹修 | 悬壶济世，丹火不熄 | 丹方、高阶药材、炼丹加成 |
| **玄岳门** | 体修 | 肉身如岳，万法不侵 | 体修功法、减伤被动 |
| **万毒窟** | 毒修 | 以毒证道，百毒不侵 | 毒修功法、毒丹方、丹毒抗性 |
| **九霄雷府** | 雷修 | 掌天雷罚，一念断罪 | 雷修功法、突破概率加成 |
| **幽冥魔宗** | 魔修 | 逆天而行，掠夺成道 | 魔修功法、模拟点掠夺 |
| **太乙符宗** | 混元（雷/体） | 以符驭法，以阵困仙 | 跨流派功法、符阵（Phase 7 扩展） |
| **天音寺** | 混元（丹/体） | 梵音洗心，心境不染 | 跨流派功法、心魔抗性、丹毒抗性 |

**六个单流派宗门 + 两个混元宗门。** 单流派给最强的专精路线；混元给跨流派功法和独特的抗性被动，是走「万法归一」或「阴阳互济」共鸣的捷径。

---

## 二、加入流程

| 途径 | 条件 | 说明 |
|---|---|---|
| 开局选择 | 入道时可跳过 | 直接以外门弟子身份开局 |
| 事件邀请 | 境界达标 + 流派匹配 | 约 12 个入宗事件，按境界分段触发 |
| 主动投奔 | 走到宗门驻地（事件） | 无流派匹配要求，但初始贡献较低 |

**散修路线是完整可行的**——不入宗也能通关，只是少了宗门资源。**验收断言：散修与宗门弟子的最终等级中位数相当（±10%）**，即入宗是"选择"而不是"税"。

### 叛宗

```
叛宗条件：当前宗门 tension 对其他宗门 ≥ 80，或收到更高职位邀请
代价：当前贡献清零、该宗门声望归负、触发追杀事件链
收益：可立即加入新宗门，且继承 30% 贡献
defections 计数影响结局文案与传承点
```

## 三、贡献与职位阶梯

### 职位

| rank | 职位 | 晋升贡献 | 俸禄（每年，走 tick 槽 6） |
|---|---|---|---|
| 0 | 外门弟子 | 0 | 悟性 +1 |
| 1 | 内门弟子 | 100 | 悟性 +2，药材 ×2 |
| 2 | 真传弟子 | 300 | 悟性 +3，药材 ×4，**宗门功法池开放** |
| 3 | 长老 | 700 | 悟性 +5，药材 ×6，丹药 ×1 |
| 4 | 宗主 | 1500 | 悟性 +8，药材 ×10，丹药 ×2 |

**晋升是单向的**（贡献不清零，但降级需叛宗或大比失利）。

### 贡献来源

| 来源 | 贡献 |
|---|---|
| 宗门任务 | 15-60（按任务难度） |
| 大比排名 | 第 1 名 +200，前 10 +80，前 50 +30 |
| 事件 | 约 20 个事件给贡献 |
| 同门羁绊 | 每级 +10% 贡献获取 |

## 四、宗门任务

**约 30 个任务**，复用事件的 `Choice` / `Outcome` 结构（见 [tech/02-effect-dsl.md](../tech/02-effect-dsl.md)）。

```ts
interface Mission {
  id: MissionId;
  sect: SectId;
  title: string;
  body: string;
  minRank: number;              // 最低职位要求
  levelMin: number;
  levelMax: number;
  cooldownYears: number;        // 8-20，可重复接取
  choices: Choice[];            // 2-3 个选项
  reward: { contribution: number; insight?: number; herb?: ...; art?: ArtId };
}
```

### 任务类型分布

| 类型 | 数量 | 特点 |
|---|---|---|
| 采集/护送 | 8 | 低风险，低贡献 |
| 讨伐/镇守 | 9 | 中风险，需战力，失败扣贡献 |
| 交涉/调解 | 6 | 需气运，影响 tension |
| 秘境探索 | 4 | 高风险高回报，可能得功法 |
| 宗门秘辛 | 3 | 剧情向，影响叛宗线 |

**任务不阻塞 tick**——它们是可接取的"界面"，不是强制打断（见 [plan/03-risks.md R5](../plan/03-risks.md#r5)）。

## 五、宗门大比

**每 20 年一次**（第 20、40、60、80 年）。

```
规则：
  按总战力排名，与同境界的 NPC 弟子比较
  排名 = 在同境界弟子池中的位置（池大小随宗门等级与境界变化）

奖励：
  第 1 名    → 贡献 +200，宗门功法 ×1，声望大涨
  前 10      → 贡献 +80，悟性 +10
  前 50      → 贡献 +30
  未入围     → 无
```

**大比是"界面"而非"打断"**：到年份时在宗门页面出现红点提示，玩家随时可以进入比试。不弹窗。

大比夺魁是**非事件途径获取宗门功法的唯一方式**，所以对走宗门路线的玩家很重要。

## 六、跨宗张力与叛宗

```ts
tension: Record<SectId, number>   // 0-100，对每个其他宗门的紧张度
```

| 行为 | 张力变化 |
|---|---|
| 完成任务（讨伐类） | 对目标宗门 +5-10 |
| 交涉/调解任务 | 对目标宗门 −5-10 |
| 宗门冲突事件 | 双方 +15 |
| 时间流逝 | 每年 −1（自然缓和） |

**张力 ≥ 80 时**触发叛宗事件链：
1. 对方宗门发出邀请（可选：接受 → 叛宗 / 拒绝 → 张力 −30）
2. 若接受：当前宗门追杀事件链（3 个连锁事件）
3. `defections++`，影响结局文案与传承点（叛宗者的传承点系数 ×1.15，但历史职位记录保留最高值）

**张力系统的作用**：让"参与宗门政治"变成一个真实的取舍——讨好一方必然得罪另一方。

## 七、按局 vs 持久

| 数据 | 生命周期 |
|---|---|
| 当前宗门 `sect.id` | **每局重置**（这一世从外门重新爬） |
| 贡献 `sect.contribution` | 每局重置 |
| 职位 `sect.rank` | 每局重置 |
| 张力 `sect.tension` | 每局重置 |
| 叛宗次数 `sect.defections` | 每局重置 |
| **历史最高职位** `sectLegacy: Record<SectId, number>` | **跨局持久** |

**持久的历史职位用于**：
- 传承点结算加成（每有 1 个宗门达到长老以上 +50 传承点）
- 解锁专属开局选项（曾在某宗达到宗主 → 新局可直接以内门弟子身份开局）
- 成就（八宗全入、全宗主）

**为什么宗门身份每局重置**：如果宗门身份跨局保留，玩家就永远在同一个宗门，八个宗门的设计就浪费了。重置让"这一世走剑宗、下一世走毒窟"成为自然选择，也是长期养成的动力来源。

## 八、验收标准

| 项 | 断言 | 命令 |
|---|---|---|
| 入宗是选择不是税 | 散修与宗门弟子最终等级中位数相当（±10%） | `tsx tools/balance.ts` |
| 晋升可达 | 一局 90 年可达到 rank 3（长老） | `tsx tools/sim.ts --sect` |
| 大比正常 | 每 20 年触发一次，排名分布合理 | `tsx tools/sim.ts --sect` |
| 叛宗可达 | 500 局种子中叛宗事件在满足条件时至少触发一次 | `npm test -- sect` |
| 贡献经济平衡 | 完成约 60% 可接任务即可从外门升到长老 | `tsx tools/balance.ts` |
