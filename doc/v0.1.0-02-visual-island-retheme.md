## 一、背景与目标

### 背景

Phase 0 交付的深色外壳在验收上是合格的（0.1-0.6 全绿），但视觉方向本身被用户推翻：要求改用 [`animal-island-ui`](https://github.com/guokaigdg/animal-island-ui) 的设计语言——**奶油羊皮纸浅底 + 暖褐文字 + 薄荷青主色 + 大圆角胶囊 + 像素堆叠 3D 按钮**的治愈系岛屿风格。

这是一次**方向性的推翻**，不是微调：

| | 原方向 | 新方向 |
|---|---|---|
| 底 | 深色夜空，靠发光表达层次 | 奶油浅底，靠厚度与描边表达层次 |
| 主色 | 金 `#d4a94a` | 薄荷青 `#19c8b9` |
| 字形 | 宋体 + 黑体的衬线反差 | 全圆体无衬线（Nunito + 系统中文） |
| 形状 | 4-22px 小圆角 | 12-24px + 50px 胶囊，**禁止直角交互元件** |

## 三、技术方案

### 3.1 设计语言的落地方式：零依赖移植

**只复用设计语言，不引入库。** Token 值、几何参数、剪影路径、设计法则**直接取自**参考库的 `docs/design-system/`（`design-tokens.md` / `design-rules.md` / `css-variables.md` / `components/*.md`），用零依赖 CSS 重实现。

两处签名级构造需要精确数据，已从组件规格中取原文：

- **Modal 的 SVG blob 剪影**：`clipPathUnits="objectBoundingBox"` 的完整 `path d`，落在 `index.html` 的 `<defs>` 里
- **Title 的燕尾丝带**：燕尾 `clip-path` 多边形、折角 `border` 三角、`perspective(11.5em) rotateX(3deg)` 前脸透视

### 3.2 字体：Nunito 自托管 + 系统中文

| 项 | 决策 |
|---|---|
| 拉丁/数字 | Nunito 变量字体（wght 200-1000），39 KB woff2，**打包进仓库**，OFL 协议 |
| 中文 | 系统栈 `PingFang SC` / `Hiragino Sans GB` / `Microsoft YaHei` / `system-ui` |
| 隔离手段 | `@font-face` 的 `unicode-range` 锁死拉丁区段，**中日韩汉字不进该 face，不产生中文字形下载** |
| 数字对齐 | 取消等宽字体（参考硬规则禁止 UI 用系统等宽），改 `font-variant-numeric: tabular-nums` |

**为什么不用 Noto Sans SC：** CJK 子集化到游戏所需的 ~1200 字仍需 300-600 KB，直接破坏包体预算；CDN 方案违反零网络约束且中国网络下不可靠。

### 3.3 主色分两条轨道（本批次最重要的技术决策）

**参考库的调色板偏浅，白字压在主色上不达标。** 实测：白字 on `--primary #19c8b9` = **2.1:1**，远低于 4.5:1。参考库自己的主按钮就是这个组合。

本作的处理：**把主色拆成两条轨道**——

- `--primary #19c8b9`：**装饰轨道**。描边、图标、大面积色块、focus ring、卡片 pattern。**不承载小字。**
- `--primary-deep #0d7a71`：**信息轨道**。承载白字的按钮底、进度填充、强调文本。白字实测 **5.2:1**。

同理，参考库的 `@text-color-muted #8a7b66` 只达 3.9:1，**不足以承载元信息**。本作的 `--ink-3` 主动加深到 `#6f6250`（5.3:1）。

这两条是**刻意的偏离**，理由与实测值都记在 [04-visual §八](tech/04-visual.md#八无障碍与对比度)。无障碍是本作的硬验收项（[plan/02 §7.4](plan/02-acceptance.md)），不能为了像素级忠实让路。

### 3.4 氛围层：从三层减到零伪元素

深色版需要 `body::before`（噪点压色带）+ `body::after`（星野 + 90s 漂移动画）。浅色羊皮纸底没有色带问题，**波点本身就是纹理**：

```css
body {
  background-color: var(--bg-page);
  background-image: var(--amb-a), var(--amb-b),
    radial-gradient(circle, var(--dots) 1.5px, transparent 1.6px);
  background-size: auto, auto, 24px 24px;
}
```

**副作用：z-index 阶梯少两层。** 不再需要"氛围 0 / 内容 1"的分层，`#root` 的 `z-index: 1` 可以去掉。`云涌` 动画词条随之删除。

### 3.5 生产包体增量预算

| 产物 | 预估增量 | 说明 |
|---|---|---|
| Nunito woff2 | +39 KB（未压缩，**不参与 gzip**） | 首屏实际下载；`unicode-range` 隔离，中文不下载 |
| CSS | ±0（替换而非新增） | 浅色版氛围层更简单，但组件配方（blob / 丝带 / 3D 阴影）更复杂 |
| JS | ±0 | 无新增依赖 |
| HTML | +~1 KB | blob `<clipPath>` 内联 |
| **gzip 合计** | **约 +0**（基线 75.4 KB） | 预算 200 KB，余量充足 |

> 字体是**独立于 gzip 首屏预算**的一项：它走 `font-display: swap`，不阻塞渲染。但它计入"打开就能跑"的体感——39 KB 是本批次可接受的上限。

## 六、风险与对策

| # | 风险 | 对策 |
|---|---|---|
| R1 | **对比度集体不达标**：参考调色板整体偏浅，照抄会在多处破 4.5:1 | 已预先实测并拆出 `--primary-deep` 与加深的 `--ink-3`（§3.3）；验收 2.7 全表复查 |
| R2 | **字体未生效但看不出**：`unicode-range` 写错会让中文也去命中 Nunito，或 Nunito 根本不加载，两者都不会报错 | 验收 2.9 用 computed style 实测；`font-display: swap` + 系统回退保证最坏情况不白屏 |
| R3 | **blob 剪影把内容切掉**：`objectBoundingBox` 随尺寸拉伸，边缘内缩很大 | 弹层宽度固定在 360px；padding 给到 48px（规格值）；移动端切底部抽屉并 `clip-path: none` |
| R4 | **3D 阴影滥用**：本作按钮多，容易给每个按钮都挂 `--shadow-3d`，界面立刻变重 | 硬规则 5 写进反模式速查表；只有主按钮与危险主按钮挂 |
| R5 | **波点底纹过重**：日志流是长文本区，底纹一重就干扰阅读 | `--dots` 透明度压到 0.055；实测时专门看满屏日志的可读性 |
| R6 | **丝带用太多**：丝带很重，每个面板都挂会吵 | 只给主面板标题与品牌名；其余面板用简洁标题 |
| R7 | **包体超预算** | 字体不计入 gzip；CSS 是替换不是新增；构建后核对 |

### 踩到的坑

1. **CSS 注释里的 `--r-*/--island-*` 提前闭合了注释。** `*/` 出现在注释正文中会直接结束注释，后面两行中文变成 CSS 语句，PostCSS 报 `Unknown word ≥3`。**后果远比想象严重：不是样式丢失，而是 dev server 的 CSS transform 整体失败 → 模块加载失败 → `#root` 完全空白，整个应用挂掉。** 构建当时恰好是在引入该注释之前跑的，所以没暴露。已在 `src/ui/*.css` 上补了一条检索（含 `*/` 但不以 `*/` 结尾的行）作为检查手段。

2. **`display: none` 子树里的 computed transform 读到 `none`，差点误判丝带透视没生效。** 第一次测得 `--gold`-on-`--r-*` 那批读数时，`.rail` 在移动断点下是 `display: none`，其内的丝带 `transform` 返回 `none`；切到桌面断点后正常返回 `matrix3d`。教训：**结构化断言必须选当前断点下可见的元素**，否则会得到"看起来是 bug 的读数"并浪费时间。

3. **参考库的调色板不能直接照抄——它的主按钮自己就不达标。** 白字压 `#19c8b9` 只有 2.1:1。这不是"实现细节"而是设计系统层面的无障碍缺口。本作把主色拆成两轨、并额外造了 5 档文本色阶才达标。**如果按"像素级忠实"照搬，交付的会是一套不可读的界面。**

4. **参考库的字体规格有歧义。** `design-tokens.md` 说字体"两种方式交付"：装库则 `@fontsource` 打包，不装库则从 Google Fonts 引入。但**它没有给出"不装库且不联网"这条路径**——而那正是本作的约束。最终自行从 `@fontsource-variable/nunito` 取 latin 变量字体（39 KB），并用 `unicode-range` 把中日韩锁在外面，才同时满足零网络与"不下载中文字形"。

5. **应用内浏览器截图通道仍不可用**（`visibilityState: hidden`，viewport 0×0，与 Phase 0 同因）。不再走 Phase 0 的 headless CDP 路径，改用 **iframe 精确视口模拟**：在同页创建指定宽高的 iframe 指向同一 URL，`getComputedStyle` 读其内部——media query 会按 iframe 的视口求值。这比 CDP 更轻，且能同时覆盖 5 个宽度。**局限：仍拿不到像素级截图，视觉"好不好看"这一层没有机器证据。**
